SVM Machine Learning Pipeline

Alur kerja dari data mentah hingga menjadi keputusan klasifikasi.

1. Raw Data Input

Input berupa angka mentah (Total Belanja, Usia, dsb) dari database pelanggan.

2. Preprocessing

Normalisasi data agar memiliki rentang yang serupa (misal: Total Belanja / 10^6).

3. SVM Algorithm

Menghitung Score menggunakan Vektor Bobot (\(w\)) dan Bias (\(b\)) yang optimal.

4. Classification Output

Output akhir: Penentuan Label +1 (Loyal) atau -1 (Reguler).

Keunggulan Pipeline SVM

Dibandingkan algoritma lain, SVM sangat tangguh dalam menangani data dengan outlier karena ia hanya fokus pada data yang berada di dekat garis pemisah (Support Vectors).
